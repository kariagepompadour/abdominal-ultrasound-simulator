# 腹部エコーシミュレーター v43：Web版配置用ファイル

このフォルダーにはWeb版に必要な画面、接続中継サーバー、テスト、配置設定、本体のライセンス、QR生成ライブラリとそのライセンスが入っています。Macのローカル証明書、秘密鍵、旧版、Cardputer ADVのファイルは入っていません。

変更後は `python3 -B -m unittest discover -s tests -v` で接続分離と配信対象を確認できます。`-B` はテスト時に一時的な `__pycache__` を作らないための指定です。

## 最短の配置手順

1. GitHubで新しいリポジトリを作り、**このフォルダーの中身**をリポジトリの最上位に置く。旧ローカル版のフォルダーやGit履歴は持ち込まない。
2. Renderで **New → Web Service** を選び、そのGitHubリポジトリを接続する。言語は **Docker**、Dockerfileは最上位の `Dockerfile`、試験時のプランは **Free** を選ぶ。
3. 配置が完了したら、PCで `https://<Renderが発行した名前>.onrender.com/web` を開く。表示されたQRをスマホで読み、スマホ画面でセンサーを許可する。

GitHubへファイルを置くだけではWeb版は起動しません。Renderが画面と通信中継を一緒に動かし、HTTPS証明書も管理します。RenderのWeb Serviceには公開URLが付くため、試験時もURLを知る第三者がアクセスできます。

## 動作条件

- Pythonを実行できるWebサービスで、`Dockerfile`から起動する。
- 公開側はHTTPSを提供し、ブラウザがアクセスしたホスト名を`Host`ヘッダーとしてアプリへ渡す。
- アプリは環境変数`PORT`のポートでHTTPを受ける。Dockerfileの初期値は8080。
- 接続状態はメモリ内にあるため、試験段階では1インスタンスで運用する。再起動時にはQRを作り直す。
- ヘルスチェックは`/healthz`、PC画面は`/web`。

PCとスマホで同じHTTPSサイトを開き、PC画面のQRをスマホで読み取ります。スマホでは画面の開始ボタンから姿勢センサーを許可します。各端末に証明書や秘密鍵を設定する必要はありません。

## 公開前

現時点では、スマホ実機でのWeb版のチルト、複数端末、切断・再接続を未確認です。医学的な正常像も専門医による照合前です。アクセス制限のないURLへ配置すると、ソースコードが非公開でもサイトは誰でも利用できます。試験公開の範囲とアクセス制限を決めてから配置してください。
